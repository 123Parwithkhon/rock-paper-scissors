# ✊ ✋ ✌️ Rock Paper Scissors Game

An interactive web-based implementation of the classic "Rock, Paper, Scissors" game. Play against the computer, track live scores, and enjoy instant win/lose/draw feedbacks with modern icon buttons.

## 🚀 Features
* Play against a randomized computer choice generator[cite: 18].
* Real-time score counter for both you and the computer[cite: 17, 18].
* Visual color-coded feedback for game outcomes (Win, Lose, Draw)[cite: 18].
* FontAwesome icons for clean and intuitive weapon buttons[cite: 17].

## 🛠 Technologies Used
* **HTML5** (Semantic structure, FontAwesome integration)[cite: 17]
* **CSS3** (Linear gradients, Flexbox layout, dynamic container styling)[cite: 19]
* **JavaScript** (Game logic, object-based rules mapping, DOM updates)[cite: 18]

## 💻 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser[cite: 17].

# ✊ ✋ ✌️ Игра «Камень, ножницы, бумага»

Интерактивная веб-реализация классической игры. Сражайтесь с компьютером, следите за текущим счетом в реальном времени и получайте мгновенную визуальную оценку победы, поражения или ниши с удобными иконками[cite: 17, 18].

## 🚀 Особенности
* Игра против случайно генерируемого выбора компьютера[cite: 18].
* Подсчет очков в реальном времени для вас и компьютера[cite: 17, 18].
* Цветовая индикация результатов игры (победа, поражение, ничья)[cite: 18].
* Иконки FontAwesome для наглядных кнопок выбора[cite: 17].

## 🛠 Используемые технологии
* **HTML5** (структура, подключение шрифтов и иконок)[cite: 17]
* **CSS3** (линейные градиенты, макет Flexbox, стилизация контейнеров)[cite: 19]
* **JavaScript** (логика игры, правила через объекты, обновление DOM)[cite: 18]

## 💻 Как запустить
1. Клонируйте или скачайте этот репозиторий.
2. Откройте файл `index.html` в любом веб-браузере[cite: 17].
